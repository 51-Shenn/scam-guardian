Web and AndroidOn desktop web the wallet runs inside a phone frame. On Android and narrow web there is no frame: tapping the phone opens the wallet full screen, because the device already is the phone.
What is simulatedMock money, fixture call and paste signals, demonstration rules. The pause is 10 seconds here so the directions can be compared quickly. The app uses 30.
Mixing is fineType, art and layout are separable. Mango Grotesque over the Tide fluid, or the Signal console under the Current hero, are both reasonable requests.
